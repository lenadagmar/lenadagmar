Projects

Examples of work that made an impact.

Business users in Mexico were translating 6000+ manufacturing documents from English to Spanish by hand. This was not secure nor efficient. I built a tool that translates the document, preserves formatting exactly (even when word order switches), and extracts text within images. It also features a customizeable glossary so users can give the AI predetermined translations for specific words or phrases. It's a full-stack web app built in Python, with Flask and HTML/CSS/Javascript. I owned the project through initial requirements gathering to deployment in production for the Mexico team. The tool has been presented to our CIO and will be extended to use cases for 12,000 business users across departments.

Users were inspecting hundreds of red bubbles on pdfs and manually entering the corresponding text into Excel spreadsheets. I am building a tool to read manufacturing drawing PDFs, extract text that corresponds to red "bubble" labels across the page, and export the information to an excel format. The tool uses OCR to detect the bubbles on each page and draw a box around the nearby text they reference. A visual model extracts the text. Users can visualize the boxes drawn on the pdf and add/delete/edit/resize/refresh the boxes. A comparison feature will also be introduced to detect differences between old and revised PDFs. It's a full-stack web app built in Python, with Flask and HTML/CSS/Javascript, currently in development.

RateMySchedule won 1st place in the SteelHacks Hackathon. Colege students have too many factors to consider when building their class schedules. RateMySchedule delivers a "rating" to a student's sample class schedule, by analyzing the timing between classes compared to class locations, the professor ratings on RateMyProfessor, and the credit load. RateMySchedule helps students build a better schedule, so they won't have to run across campus with only 10 minutes between classes, or be stuck with a poorly rated professor. It's a full-stack web app built in Python with Flask and React.js, leveraging several APIs, including Gemini for AI analysis, rating and summarization.

"Doomscrolling" can cause people to lose hours of their lives each day to a screen. DoomScroll Diary is a class project that helps users to track their screentime by app, create goals, see trends, make diary entries, and keep streaks. It implements user login, and is built in Python, with Flask, SQLite3, and Docker. I worked in a team of 6 using the Scrum framework for development.
